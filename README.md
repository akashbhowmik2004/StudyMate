# StudyMate 🚀

StudyMate is a collaborative learning platform designed for students to discuss academic doubts, participate in study communities, and organize notes subject-wise.

## Problem Statement

Students often use multiple platforms for asking doubts, storing notes, and participating in study discussions. StudyMate aims to bring all these features together in a single platform.

## Planned Features

### Community System

* Create study communities
* Join communities
* Community-based discussions

### Doubt Discussion Platform

* Post academic doubts
* Comment on doubts
* Like discussion posts
* Community-specific doubt feeds

### Notes Management

* Create notes
* Organize notes by subject
* Edit and delete notes
* Personal study repository

### User Authentication

* Secure signup and login
* JWT authentication
* Protected routes
